# Issue tracker

## Source of truth

This repository tracks work in **Linear**, not GitHub Issues.

Use the repository's configured Linear MCP integration for issue discovery, creation, updates, comments, status changes, and project/cycle coordination. Do not create or triage work through GitHub Issues unless the workflow is explicitly changed.

The applicable Linear team, project, cycle, assignee, and status should be selected from live Linear data rather than inferred from repository metadata.

## Pull requests

Pull requests are implementation and review surfaces, not the issue tracker. Link a pull request to its Linear issue when the Linear workflow supports that association.

## Related skill behavior

Skills that need to turn plans into work items should create or update Linear issues through MCP. Triage should use the configured Linear workflow and the label vocabulary in `docs/agents/triage-labels.md`.

To switch this repository to another tracker, update this file and the corresponding `## Agent skills` block in `AGENTS.md`.
