# Triage labels

This repository uses the default canonical triage vocabulary:

| Role | Label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs information | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

These labels are role names, not necessarily labels that should be created automatically. When operating in Linear, first resolve the matching existing labels and team conventions through MCP. Do not create duplicate labels without explicit instruction.

If the repository's Linear label vocabulary changes, update this file and the `Triage labels` section in `AGENTS.md`.
